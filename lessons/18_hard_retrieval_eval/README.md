# 第 18 课：困难检索评估与 MRR

上一课的问题与文档原文非常接近，两种检索方法都得到满分。本课使用更自然的同义改写、概念辨析和相邻主题问题，降低测试数据与原文措辞重合造成的虚高。

本课同时计算三个指标：

- `Recall@1`：正确文档是否排在第 1 位
- `Recall@2`：正确文档是否出现在前 2 位
- `MRR`：根据正确文档的具体排名计分，越接近第 1 位得分越高
